# 🌐 Year-Long Vision: Network Breach — Full Release Plan

## Goal
Expand **Network Breach** from a single-level Early Access demo into a complete, polished indie game with multiple networks, endless mode, leaderboards, speedruns, and a free demo — all within **12 months**.

---

## 🎯 Core Philosophy

- **Early Access** (Month 1): 1 network, core mechanics, paid ($5–10)
- **Mid-Development** (Months 2–6): Add content, polish, community feedback
- **Late-Stage** (Months 7–11): Feature completion, optimization, marketing ramp-up
- **Full Release** (Month 12): Polished game + free demo version for new players

**Hard Rules:**
- ✋ **NO unlimited scope creep** — Only features below get added
- ✋ **Feedback-driven, not wishlist-driven** — Prioritize what players actually want
- ✋ **Solo dev sustainable pace** — Burn-out prevention is priority

---

## 📊 Full-Release Feature Set

### ✅ Included in Full Release

#### Core Gameplay (Already in Early Access, Enhanced)
- Multiple difficulty tiers for existing network
- Refined balance & edge cases
- Performance optimization
- Better UI/UX refinements

#### New Networks/Levels (3–4 Additional)
- **Corporate Mainframe** (established in EA, expanded)
- **Government Secure Network** (more difficult, unique enemies)
- **City Infrastructure Grid** (procedural variations)
- **International Quantum Node** (final "hardest" network)

**Style:** Each network has unique visual theme + lore snippet

#### Tower Types (Expanded from 3 → 6–7)
- Firewall (existing)
- Antivirus Pulse (existing)
- Packet Bomb (existing)
- Proxy (support tower from original doc)
- **NEW:** Honeypot (lures enemies to weak spot)
- **NEW:** DDoS Amplifier (delayed area damage)
- **NEW:** Encryption Layer (shields nearby towers temporarily)

#### Enemy Types (Expanded from 3 → 5–6)
- Crawler (existing)
- Injector (existing)
- Overseer (existing)
- **NEW:** Worm (splits into smaller enemies when killed)
- **NEW:** Trojan (disguises as resource, damages towers when opened)
- **NEW:** Rootkit (invisible/camouflaged, unpredictable behavior)

#### Game Modes
- ✅ **Campaign Mode** (play through 4 networks sequentially)
- ✅ **Endless Mode** (single network, infinite waves, see how long you last)
- ✅ **Speedrun Mode** (complete network in fastest time, leaderboards)
- ✅ **Daily Challenge** (daily curated preset with one-time leaderboard)

#### Progression & Customization
- Meta-progression unlocks (new towers, passive buffs, visual skins)
- Persistent upgrades between playthroughs
- "Corruption Level" system (cosmetic AI advancement)
- Optional cosmetic skins for towers (thematic variations)

#### Leaderboards & Social
- Global leaderboards per mode (campaign, endless, speedrun, daily)
- Steam achievements (15–20 total)
- Replay/clip sharing (capture best moments)
- Local score history

#### Free Demo Version
- **For full-release marketing** (launch alongside full release)
- Single introductory network (easier than Early Access version)
- 15–30 min playtime
- Clear upgrade path to full game
- Serves as "try before you buy"

#### Story & Lore (Minimal, Environmental)
- Terminal logs/messages between levels
- "Corruption diary" entries (AI perspective)
- Subtle world-building (humans react to your spread)
- Optional expanded lore post-launch (community engagement)

#### Art & Polish
- Full sprite set for all towers & enemies (8–16 sprite variations each)
- Particle effects for all attacks
- Animated UI transitions
- Visual feedback for all player actions
- Cyberpunk theme consistent across all networks
- Optional: Cosmetic "corrupted AI" visual upgrades as unlocks

#### Audio
- Unique 2–3 minute and 3-4 song soundtrack for each network
- Full SFX library (spawn, attack, capture, upgrade, loss, win)
- Optional: Short AI voice lines (rare, flavor text)
- Mute/volume controls

#### Performance & Polish
- Runs on low-spec machines (target: 60 FPS on 2018-era hardware)
- Full controller support (gamepad friendly)
- Accessibility options (colorblind mode, text scaling, etc.)
- Bug-free or near-bug-free experience

### ❌ Explicitly NOT Included

- ❌ Custom level editor (too much scope, players won't use it)
- ❌ PvP/Co-op multiplayer (servers, matchmaking = complexity)
- ❌ Mobile port (different ecosystem, not now)
- ❌ VR support (development overhead)
- ❌ Advanced procedural generation (static + minor variation is cleaner)
- ❌ Story campaign beyond environmental logs (keep it light)

## 💰 Monetization & Revenue Plan

### Primary Revenue Stream: Game Sales
- **Early Access** (Months 1–12): $5–10 per copy
- **Full Release** (Month 12+): $9.99–14.99 per copy (slight price bump at full release)
- **Estimate:** 200–500 copies by end of year = $2K–7.5K

### Secondary: Patreon
- **Launch:** Month 1 (concurrent with Early Access)
- **Target:** 30–50 backers by month 12 = $200–400/month recurring
- **Tiers:**
  - Tier 1 ($3/mo): Early builds, monthly devlog
  - Tier 2 ($10/mo): Exclusive devlog + name in credits
  - Tier 3 ($20+/mo): VIP (voting on features, custom tower naming)

### Tertiary: Optional Future (Post-Launch)
- Cosmetic DLC packs (tower skins, network themes) — **NOT in Year 1 plan**
- Soundtrack purchase (Itch.io, Bandcamp) — optional
- Art book/behind-the-scenes — optional

### Revenue Target for Year 1
- **Conservative:** $2.5K–3K (covers dev costs, asset purchases)
- **Moderate:** $4K–6K (comfortable year 1 outcome)
- **Optimistic:** $7K–10K (strong indie success)

**Use:** Reinvest into marketing, music licensing, professional art polish, next project

✅ Focused on player value & sustainable development
