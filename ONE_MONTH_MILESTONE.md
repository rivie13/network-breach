# 🎯 One-Month Milestone: Network Breach Early Access Launch

## Goal
Release a **paid Early Access version** on Steam within **4 weeks** with a playable, monetizable demo.

---

## 📋 Demo Scope (Non-Negotiable)

### Core Features
- ✅ 1 fully playable level (single expandable network map)
- ✅ 3 tower types (Firewall, Antivirus Pulse, Packet Bomb)
- ✅ 3 enemy types (Crawler, Injector, Overseer)
- ✅ Wave-based defense system with final "boss wave"
- ✅ Network expansion mechanic (nodes unlock as you capture)
- ✅ Resource system (Data, Bandwidth, CPU cycles)
- ✅ Rogue-lite upgrades (3 choices per wave, with buffs/detriments)
- ✅ Leaderboards integration (Steamworks)
- ✅ Main menu, pause menu, settings

### Out of Scope (For Now)
- ❌ Multiple levels/networks
- ❌ Endless mode (post-launch update)
- ❌ Custom level editor (strong maybe → leaning NO)
- ❌ PvP/Co-op modes
- ❌ Advanced procedural generation
- ✋ **NO SCOPE CREEP** — Stay focused!

## 🚨 Risk Mitigation

| Risk | Mitigation |
|------|-----------|
| Scope creep (adding new towers/levels) | **Hard stop at Week 2 features. NO changes to scope.** Document feature requests for post-launch. |
| Steam submission takes too long | Submit mid-Week 4. Account verification early (Week 1). |
| Art not done in time | Use free/AI-generated assets. Iterate visuals post-launch. |
| Bugs found late | Weekly builds & playtesting. Allocate 2–3 days for fixes. |
| No players at launch | TikTok/YouTube devlog community → built-in audience. Encourage reviews. |
